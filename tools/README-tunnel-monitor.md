# Система мониторинга Cloudflare туннеля

## Описание
Автоматическая система мониторинга Cloudflare туннеля с перезапуском при сбоях и уведомлениями в Telegram.

## Компоненты

### 🔍 `monitor-tunnel.sh`
Проверяет работоспособность туннеля:
- Извлекает URL из логов Docker
- Делает HTTP-запрос к `/api/ping`
- Возвращает код выхода 0 (OK) или 1 (проблема)

### 📨 `send-tunnel-url.py`
Отправляет уведомления в Telegram:
- Читает токен из `.env`
- Отправляет сообщение пользователю с новым URL

### 🚀 `check-and-restart-tunnel.sh`
Главный скрипт, объединяющий всю логику:
- Запускает мониторинг
- При обнаружении 503 перезапускает туннель
- Отправляет уведомление с новым URL

### ⏰ Cron-задание
Запускается каждые 5 минут:
```bash
*/5 * * * * /home/aert14/city_fog_map/tools/check-and-restart-tunnel.sh >> /home/aert14/city_fog_map/tunnel-monitor.log 2>&1
```

## Настройка Telegram

Для работы уведомлений необходимо получить chat_id пользователя aert14:

1. **Вариант 1**: Напишите сообщение боту [@city_fog_map_bot](https://t.me/city_fog_map_bot)
2. **Вариант 2**: Вручную укажите chat_id в коде (для тестирования)

Если chat_id не найден автоматически, скрипт попросит ввести его вручную.

## Логи
Логи работы системы сохраняются в `tunnel-monitor.log` в корне проекта.

## Тестирование
Запустите тест всей системы:
```bash
./tools/test-tunnel-system.sh
```

## Ручной запуск
Для тестирования можно запустить компоненты вручную:
```bash
# Проверить туннель
./tools/monitor-tunnel.sh

# Отправить тестовое уведомление
python3 tools/send-tunnel-url.py aert14 https://test-url.trycloudflare.com

# Полный цикл проверки
./tools/check-and-restart-tunnel.sh
```
